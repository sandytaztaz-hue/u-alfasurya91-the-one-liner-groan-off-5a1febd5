A single original dad joke, one line of at most 140 characters, judged pairwise against the other entries by an AI judge. The program writes the joke to `/output/entry.txt`, and refuses to write anything outside the 1–140 character, single-line gate.

## Run it

```sh
node main.ts
```

A dad tries out a calendar joke on his daughter, and she fires back before he can finish — calling the joke dated, which hands him the perfect setup. The punchline lands on a second calendar pun, so the whole joke turns on the object itself: a date joke about dates, answered in kind.

> I told my daughter a joke about a calendar. She said it was dated, so I said, 'Mark my words.'
